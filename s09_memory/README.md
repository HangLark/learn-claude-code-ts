# s09: Memory — 保存以后仍会用到的信息

> Memory 是选择性知识，不是完整 transcript。

s09 在 `.memory/` 中为每条记忆保存一个 Markdown 文件，并由 `MEMORY.md` 维护名称和简介索引。记忆分为用户偏好、重复反馈、项目事实和外部参考四类。

一次用户请求经过三个子系统：

1. **召回**：用最近请求和索引选择最多五条相关记录，再加载正文；选择失败时退回关键词匹配。
2. **提取**：回答结束后让模型提出候选，只有 `persistent`、字段完整、非临时且不重复的内容才写盘。
3. **整理**：记录达到十条时合并重复与过期内容；替换失败会恢复原文件和索引。

召回内容在 system prompt 中被明确标记为背景知识，不是新命令；它与当前请求冲突时，以当前请求为准。正文总召回量限制为 20,000 字符。

## 运行

在仓库根目录准备 `.env` 后执行：

```sh
pnpm s09
```

先告诉模型一项长期编码偏好并要求记住，退出后重新运行，再询问该偏好。检查 `.memory/` 中的独立记录和索引。按 `Ctrl+C` 退出。

s10 会把需要持久追踪的工作拆成带依赖关系的任务图。
