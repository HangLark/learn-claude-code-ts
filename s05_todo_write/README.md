# s05: TodoWrite — 让计划留在上下文里

> 没有计划的 agent，做着做着就会偏离目标。

s05 在 s04 的工具池中加入 `todo_write`。它维护一份内存任务列表，每项状态为 `pending`、`in_progress` 或 `completed`，并把当前计划同时返回给模型、展示给用户。

`todo_write` 不执行任何工作，只让模型显式记录“接下来做什么”和“已经做到哪里”。同一时间最多一项处于 `in_progress`，避免计划本身失去焦点。

连续三个工具调用轮次没有更新计划时，harness 会在工具结果旁追加：

```xml
<reminder>Update your todos.</reminder>
```

这不是替模型编排步骤，而是在长上下文中把注意力拉回它自己制定的计划。

## 运行

在仓库根目录准备 `.env` 后执行：

```sh
pnpm s05
```

给它一个包含多个步骤的任务，观察第一次 `todo_write` 以及后续状态更新。按 `Ctrl+C` 退出。

s06 会把独立子任务放进全新的消息历史，进一步隔离上下文。
