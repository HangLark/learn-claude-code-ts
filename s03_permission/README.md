# s03: Permission — 执行前先过权限门

> 先划边界，再给自由。

s03 在 s02 的工具分发前加入三道闸门：

1. 硬拒绝列表命中后直接阻止。
2. 权限规则判断操作是否需要批准。
3. 需要批准时暂停并询问用户，默认拒绝。

```text
tool_use -> hard deny -> rule match -> user approval -> dispatch
```

权限判断属于 harness。模型仍决定调用什么工具，但只有 harness 能决定调用是否真正执行。被拒绝的调用会作为 `Permission denied.` 回填，让模型观察结果并调整下一步。

## 运行

在仓库根目录准备 `.env` 后执行：

```sh
pnpm s03
```

普通读取和工作区内写入会直接通过；删除命令或工作区外访问会询问用户；硬拒绝列表中的命令不会提供放行选项。按 `Ctrl+C` 退出。

> [!NOTE]
> 字符串规则只用于展示权限管线的位置，不是完整的 shell 安全系统。
