# s04: Hooks — 挂在循环上

> 扩展逻辑挂在固定节点，不写进核心循环。

s04 定义四个 hook 事件，覆盖一次 agent cycle：

| 事件               | 时机                  | 示例             |
| ------------------ | --------------------- | ---------------- |
| `UserPromptSubmit` | 用户输入进入模型前    | 记录或补充上下文 |
| `PreToolUse`       | 工具执行前            | 权限、日志       |
| `PostToolUse`      | 工具执行后            | 输出检查、副作用 |
| `Stop`             | agent loop 即将停止时 | 收尾或要求继续   |

s03 的权限管线被移入 `PreToolUse` 回调。循环只触发 hook：执行前 hook 返回字符串会阻止工具；Stop hook 返回字符串会把它追加为用户消息并继续循环。

## 运行

在仓库根目录准备 `.env` 后执行：

```sh
pnpm s04
```

尝试读取文件、执行普通命令和删除命令，观察同一执行节点上的日志与权限 hook。按 `Ctrl+C` 退出。

s05 会在这些稳定扩展点之外，为模型增加显式计划工具。
